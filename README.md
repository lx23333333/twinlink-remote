# TwinLink 双向远程桌面

一个简单的远程控制软件

## 为什么做这个

因为没钱充会员用todesk老被踢，化身愤怒的普通人，直接做了个简易的远程登录软件，免费且可自定义，可以用AI再根据自己的要求进行修改，画质目前最高支持1080p+144hz，只加了简单的文件拖拽能力，目前还未加入隐私屏、一键开机、双端剪切板互通等等功能，可以自己DIY，平时我得玩游戏看论文做实验，只能随缘更新

说明：1080p / 144 Hz 是当前界面提供的目标参数，实际帧率取决于两端硬件、显示模式和网络，尚未完成实机性能验收。当前已有预览版文件复制同步，尚无完整的双端文本、图片等剪贴板互通。

## 下载与开源

- [下载 Windows 1.3.1 预览版](https://github.com/lx23333333/twinlink-remote/releases/tag/v1.3.1)
- 本项目自有代码采用 [MIT 许可证](LICENSE)，可以免费使用、修改和分发；第三方组件的许可与服务条款见 [THIRD-PARTY.md](THIRD-PARTY.md)。
- 使用与构建方法见下文，验证范围见 [docs/VALIDATION.md](docs/VALIDATION.md)。

适用于两台 Windows 10/11 x64 电脑的中文远程连接工具。默认请求 **1920×1080 / 144 FPS / 50 Mbps**，支持键盘、鼠标与音频串流，可通过 Tailscale 在不同网段、不同地点连接。

这是集成客户端：本项目实现中文操作界面、组件安装入口、参数管理、配对入口和网络诊断；画面采集、硬件编解码及远程输入由 Sunshine/Moonlight 实现，跨网连接由 Tailscale 实现。首次准备需要联网安装这些组件和登录账户；分发 ZIP 不包含第三方安装包。不是独立研发的串流内核，也不是零配置、无需账户的自建远控服务。

## 立即使用

1. 将 `dist/TwinLink-Windows.zip` 复制到两台电脑，分别解压整个文件夹，双击其中的 **TwinLink.exe**。当前版本为 **1.3.1 预览**，可在窗口标题查看；升级时先关闭旧版再打开新版。请保留随包说明。无需 Python、Node 或开发环境；需要 Windows 的 .NET Framework 4.8。
2. 两台电脑分别点击 **安装三个必要组件**，会直接打开程序内的安装向导，再点击“开始安装”。此入口不再依赖外部安装脚本。安装过程中可能需要管理员权限；进度、失败原因和退出代码会显示在向导中。安装使用 Windows 应用安装程序的 winget 社区源及其哈希校验；缺少 winget 或下载失败时，点击向导内的官方链接手动安装。
3. 两台电脑分别点击 **登录跨网账户**，通过 Tailscale 托盘登录同一账户（或同一 tailnet 中获准访问的账户）。不需要配置 exit node、subnet router 或开启远程桌面服务。跨网访问仍受所在网络及 Tailscale 访问规则限制。
4. 每台电脑点击 **打开本机设置 / 输入配对 PIN**。Sunshine 默认管理页为 `https://localhost:47990`，首次建立用户名和强密码。它的本机管理页采用自签名证书，核对地址确实是 localhost 后进入。确认 Applications 中有 `Desktop`。
5. 比如 A 控制 B：在 B 点击“复制本机跨网 IP”；在 A 填入 B 的 `100.x.x.x` 地址，点击 **首次配对**。A 的 Moonlight 窗口显示 PIN；在 B 的 Sunshine 管理页 PIN 栏输入并提交。成功后 A 点击 **连接远程桌面**。
6. B 控制 A 时，交换操作方向并单独配对。两台都安装相同三个组件，所以两边均可充当被控端或控制端。建议一次只建立一个方向的会话，避免互相捕获远程画面形成递归桌面。

本机“查看准备状态”显示组件路径、Sunshine 管理端口、本机跨网 IP 和系统报告的显卡/显示模式。未知或无法读取的状态不会当成通过。Sunshine 安装器通常会注册并启动服务，若管理页不可达，请在 Windows 服务中检查 Sunshine；若安装器提示重启，保存工作后再自行重启。

## 两台电脑之间互传文件（1.1.0 新增）

1. 两台电脑都登录**同一个 Tailscale 账户**并保持在线。在 Tailscale 管理页面启用 **Send Files**（可点文件互传窗口底部的“启用文件互传”进入）。
2. 点击主窗口的 **文件互传**。填写接收电脑的 Tailscale IP 或设备名；这里会默认带入主窗口填写的地址。可以先点击“查看可接收设备”，从列表结果中核对目标。
3. 点击“添加文件”多选，或把文件拖进列表，然后点 **发送文件**。窗口按已完成的文件数显示进度，并显示当前文件与错误原因；不提供每个文件的字节百分比或实时速度。
4. Windows Tailscale 1.34 及以后版本收到文件会自动保存到接收电脑的 **下载** 文件夹，可用 **打开本机接收文件夹** 打开。本程序通过 Windows 已知文件夹接口识别系统下载目录，支持目录被重定向的情况。
5. 反向传输时，在另一台电脑执行同样步骤即可。无需先建立 Moonlight 远程桌面连接；收件端需要 Tailscale 处于可接收状态，无需保持 TwinLink 文件窗口打开。

功能使用 Tailscale Taildrop，通过现有加密连接传输，不另开自建文件接收端口。Taildrop 目前适用于同一账户拥有的个人设备；同一网络中的其他用户设备、共享设备及 tagged devices 不一定是可接收目标。以“查看可接收设备”的实际结果为准。

只支持文件，文件夹请先压缩为 ZIP。可在发送中点击“取消传输”；已经完成的文件不会从对方删除，未完成的文件可以重试。发送后原文件会保留。传输与远程画面共用网络带宽，传大文件时可能影响远控流畅度。

出现失败时查看窗口日志，并确认账户、接收端在线状态、Send Files 设置；“复制传输日志”便于提供错误信息。文件的最终保存、重名及中断恢复由 Tailscale 处理，TwinLink 不另行覆盖或删除接收端文件。官方说明见 [Taildrop](https://tailscale.com/docs/features/taildrop?tab=windows) 与 [Tailscale CLI](https://tailscale.com/docs/reference/tailscale-cli)。

1.3.1 修复：移除可能在游戏长按左键时误弹出的整块蓝色遮罩，改为只响应真实文件拖放。注册目标失败时显示原因，不退回鼠标长按猜测逻辑。

## 远程连接自带文件复制与拖拽（1.3.1 预览）

**无需打开助手、填写口令或额外启用。** 两端运行本版 TwinLink，直接从主窗口连接远程桌面，文件功能会自动协商；远程画面结束后自动停止同步。“文件状态”只用于看进度和错误，关闭状态窗口不影响会话。

首次运行时，如果 Windows 提示管理员确认，请允许程序配置本机文件连接权限；该步骤对同一路径通常只需一次，不需要每次连接操作。原有 Sunshine PIN 配对仍只需按首次远控的步骤完成。两端需登录同一 Tailscale 账户，且该账户已启用 Send Files。没有更改 Sunshine 的配对信任设置。

使用方式：

1. 控制端选中文件按 **Ctrl+C**，等待“剪贴板就绪”通知，再到远程目标文件夹或桌面按 **Ctrl+V**。反方向复制文件同样通过当前会话传输。大文件需先传完；本版不会拦截或排队尚未就绪时的 Ctrl+V。
2. 先在被控端打开目标资源管理器文件夹或单击桌面空白，再从控制端把文件拖入远程画面。鼠标显示可复制的拖放反馈后松手，文件会复制到对方当前打开的文件夹或桌面；同名文件会加编号，不覆盖原文件。
3. 直接退出远程画面即可停止本次文件同步。需要仅停止文件功能时，在“文件状态”点“停止本次文件同步”，下次远程连接会自动恢复。

关闭主窗口会留在系统托盘，保持被控端后台接收能力；双击托盘图标可以重新打开主窗口。需要彻底退出时，右键托盘图标选择 **退出 TwinLink**。两端均需保持新版程序运行，不需要再单独运行文件助手。当前没有把程序设置为 Windows 登录自启动。

连接失败、Moonlight 只打开设备列表或未出现远程画面时，不会激活剪贴板同步；等待画面最多 45 秒后结束待准备的文件会话。实际画面退出后，控制端会关闭同步连接；程序异常退出或链路失联时，接收端按连接关闭或最长约 15 秒无心跳停止。它不会在无远程会话时持续同步个人剪贴板。

### 自动连接机制

程序只绑定本机 Tailscale IPv4 的 TCP 48179，由 Tailscale 加密链路承载。开始远程连接时核对源连接 IP 与本机 Tailscale 状态，要求对方属于同一账户、在线、没有设备标签且非共享设备。通过后自动产生一次性会话密钥；每次连接使用新密钥，不让用户抄写，也不保存到磁盘。原文件包仍检查 HMAC 清单、设备地址及 SHA-256 内容摘要。身份字段的依据为 [Tailscale 1.104.4 官方状态结构](https://github.com/tailscale/tailscale/blob/v1.104.4/ipn/ipnstate/ipnstate.go)。

首次网络权限配置仅为当前 EXE 添加 TCP 48179 的入站允许规则，并将来源限制为 `100.64.0.0/10`。若拒绝首次 Windows 权限提示，或网络访问规则禁止此端口，画面仍可连接，主窗口会说明文件功能未就绪，不会把未完成的协商显示为成功。

### 本版边界

- **仍为预览版本**：110 项本地检查包含身份筛选、真实本地 TCP 自动协商、新密钥、心跳与连接关闭清理，但没有完成真实双机拖拽、Windows 剪贴板粘贴和目标位置联调。不能把这些本地测试当成实际交互已经验收成功。
- 一次支持一个远程画面。文件拖拽通过远程画面窗口的 Windows 原生 OLE 目标处理，不显示全屏遮罩，也不轮询鼠标左键。全屏模式继续使用无边框全屏。暂不支持拖到文件夹图标、聊天软件、浏览器或任意应用内部；落点是对方当前打开的文件夹或桌面。高 DPI、多显示器及窗口权限差异仍需实测。
- 默认同步新复制的文件，不同步已有剪贴板、普通文本或 Ctrl+X 剪切。原文件始终保留，不会执行收到的文件。
- 每批最多 256 个文件、总计 2 GB；文件夹请先压缩。请求超过 10 分钟会过期，慢速大文件可改用原“文件互传”窗口。
- `.tlbridge` 传输包会留在 Windows 下载目录；供粘贴的文件在 `%LOCALAPPDATA%\TwinLink\session-cache`。粘贴完成前不要删缓存，完成后可按需手动清理。程序不自动清空下载目录。
- 首次从 1.2 或更早版本升级，请更新两端。1.3.1 与 1.3.0 的文件协议兼容；本次长按误触发修复更新控制端即可生效，交换控制方向时另一端也应更新。退出旧版时请右键系统托盘图标选择“退出 TwinLink”，只关主窗口仍会在后台运行。

## 如何达到 1080p 144 FPS

客户端请求 144 FPS 不代表已经测得 144 FPS。要得到接近 144 个不同画面/秒，被控端应有 1920×1080、144 Hz 或更高刷新率的活动显示模式，或正确配置且支持该模式的虚拟显示器；控制端显示器也需至少 144 Hz 才能完整呈现。程序不自动安装虚拟显示驱动或强改刷新率。

- 被控端 GPU 需支持足够快的硬件编码，控制端需支持对应格式的硬件解码。本项目强制 Moonlight 使用硬件解码，避免误把低性能软件解码当成目标方案；不兼容时改为 H.264、更新显卡驱动或降低帧率。
- 默认编码 `auto` 交由客户端协商；可手选 H.264、HEVC、AV1。较新的格式可能更省带宽，但两端都必须支持。默认关闭 HDR，便于兼容普通桌面。
- 50 Mbps 是默认起点，不是测速结论。预留额外带宽给音频、协议开销和码率波动；跨网时被控端上行及控制端下行都必须够用。链路不稳时改 20–35 Mbps 或 120/60 FPS；降低码率会影响细节。
- 性能统计默认关闭，不在远程画面上覆盖黄色参数。只有诊断时才手动勾选“显示性能数据”；当前连接可用 Ctrl+Alt+Shift+S 切换。144 FPS 每帧约 6.94 ms；静止桌面可能降低有效更新速率，性能测试时应显示持续运动内容。
- Sunshine 支持根据客户端请求调整 Windows 显示模式。在 Sunshine 配置界面核对显示设备与分辨率/刷新率选项；本程序传递 `--game-optimization`，但驱动不支持的显示模式仍然无法实现。

## 跨网连接与故障排查

点击 **检测跨网链路**，先检查对方 Sunshine 的 TCP 47989，再运行 `tailscale ping`。前者只是控制端口连通性，不能证明 UDP 视频流、配对或目标帧率正常。

Tailscale 会尝试直连；检测输出中出现公网端点或 direct 表示直连，DERP/relay 表示经过中继。中继提供连通兜底，但并不保证 Moonlight 可用或足够吞吐，不能承诺任意网络都能跑 144 FPS。若一直中继，检查双端 UDP 出站策略、严格 NAT、企业/校园网限制。必要时需另行评估可直连网络或部署带宽充足的近端中继/VPN 服务器；本项目没有替你租用或部署公网服务器。

常见情况：

| 现象 | 处理 |
| --- | --- |
| 未找到组件 | 正常安装到默认目录后刷新；Moonlight 便携版用“选择 Moonlight 路径”指定 EXE |
| 没有本机跨网 IP | 打开 Tailscale 托盘登录并连接，再刷新；两端需要在同一获准访问的网络中 |
| 控制端口不可达 | 确认被控电脑开机、Sunshine 运行、地址正确、Tailscale ACL 允许、安装器防火墙规则覆盖该接口 |
| 可配对但黑屏/断流 | 查看 Sunshine 日志、Moonlight 错误、显卡驱动和 UDP 防火墙规则；TCP 通不代表 UDP 通 |
| 提示找不到应用 | Sunshine 中需有 `Desktop`，或把本工具的应用名称改成那里的实际名称 |
| 上限只有 60 帧 | 核对双方高级显示设置、捕获设备模式、编码器负载和网络丢帧，不以请求参数代替实测 |
| 远程电脑休眠/锁屏 | 高帧率桌面串流需活动桌面；休眠或关机时本程序无法连接，也不提供开机前控制 |
| 需要管理员安全桌面操作 | 受 Windows 会话及 Sunshine 服务权限影响；本项目未验证 UAC 安全桌面、登录界面等特殊场景 |

不要为了排错关闭整个防火墙。按 Sunshine 安装器及官方文档修正规则，并尽可能限制到自己的 Tailscale 对端。不要把 Sunshine 管理页面转发到公网。本工具只打开本机管理页，不保存 Sunshine 密码、Tailscale 密钥或配对 PIN；配对信任由第三方组件保存。被控端可在 Sunshine 中撤销配对，或停止 Sunshine 服务来撤销访问。

## 退出与数据

- 退出当前串流：**Ctrl + Alt + Shift + Q**。仅关闭 TwinLink 主窗口不会终止 Moonlight 会话，也不会停止 Sunshine/Tailscale 服务。
- 配置保存在 `%LOCALAPPDATA%\TwinLink\settings.json`，包含目标地址和画质偏好。它不会随分发包复制到另一台电脑。
- 文件传输通过 Taildrop 提供；1.3.1 预览提供随远程连接默认启用的文件剪贴板同步。没有实现普通文本剪贴板同步、远程开机、无人值守审批策略或自建账号/中继后台。
- 若不再需要被控制，在 Sunshine 撤销配对或卸载 Sunshine；卸载 TwinLink 文件夹本身不会卸载三个第三方组件。

## 开发与检查

项目结构：`src` 为 C# WinForms 源码，其中 `InstallerForm.cs` 为程序内的安装向导，`FileTransfer.cs` 与 `FileTransferForm.cs` 实现文件发送及窗口，`BridgePacket.cs`、`BridgeDesktop.cs` 与 `SessionFilesForm.cs` 为会话内置文件同步组件，`AutoFileSession.cs` 实现设备核验与自动协商；`scripts/Build.ps1` 负责用系统 .NET Framework 编译器构建，`scripts/Install-Components.ps1` 为保留的旧版手动安装脚本，主程序不使用它。`tests` 包含真实 Windows 参数解析回环、连接参数、地址校验、配置读写、窗口构造、按钮点击、进程输出/错误码、文件队列失败及取消、签名文件包内容校验与目标复制检查。

在项目目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build.ps1 -Test
```

构建结果在 `dist/TwinLink-1.3.1` 和 `dist/TwinLink-Windows.zip`。`tests/output/window.png` 是窗口离屏渲染检查，不是远程连接截图。`docs/VALIDATION.md` 记录本次验证范围。
