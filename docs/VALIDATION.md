# 1.3.1 预览版验证范围

日期：2026-10-31。平台：Windows，使用系统 .NET Framework C# 编译器构建。

## 本次改动

- 文件复制与拖拽并入“连接远程桌面”：双方运行新版即可自动准备，不再需要独立助手、口令填写或手动启用。
- 启动时在本机 Tailscale IPv4 待命，核对同一账户的在线个人设备，自动协商一次性密钥。长连接维持会话，心跳标记真实画面是否已建立；连接关闭或超时后停止同步。
- “文件状态”仅用于查看和停止本次同步，关闭状态窗口不关闭文件功能。主窗口关闭后留在托盘，右键“退出 TwinLink”可彻底退出。
- 首次网络权限配置使用 Windows 管理员确认，仅为当前 EXE 的 TCP 48179 开放来自 100.64.0.0/10 的入站访问。失败时说明原因，画面连接可以继续。
- 黄色性能统计默认关闭；加载旧版开启设置时也不会自动恢复，仅用户主动勾选诊断时开启。

- 1.3.1 修复长按误触发：删除全局左键轮询、蓝色顶层遮罩与相关窗口，直接为 Moonlight 实际画面 HWND 注册原生 OLE 文件目标。只允许完整的文件 DragEnter → Drop 流程提交，离开、停止会话或无效数据均拒绝。

## 已验证

110 项本地检查通过：

- 地址校验、原生 Windows 命令行参数往返、1080p/144 FPS/码率参数、硬件解码、设置读写与损坏回退。
- 原生安装窗口、文件互传窗口和文件状态窗口的实际按钮打开及离屏渲染；确认界面无独立助手、生成口令或启用助手的操作要求，关闭状态窗口只隐藏窗口。
- 文件发送队列、中文/空格路径、空文件、失败后停止队列、进程输出/退出代码、取消后结束本地测试进程。
- 真实本地文件包往返、HMAC 校验、内容 SHA-256 校验；错误密钥、错误设备地址、目录穿越、保留文件名、过期及超大请求拒绝；同名原文件保留，剪切数据排除。
- 对照 Tailscale 1.104.4 官方状态结构建立测试数据，验证状态解析、IP/设备名解析，以及其他账户、共享设备、标签设备、离线设备和非对端地址的拒绝。
- 真实本机回环 TCP 自动协商：无需提供手动密钥、每次新连接生成不同密钥、未建立画面时保持非活动状态、画面就绪心跳、关闭连接后对端收到结束事件、拒绝会话错误传回客户端、控制消息大小限制。这些连接只发生在 127.0.0.1，不连接另一台电脑。
- 默认连接参数包含 --no-performance-overlay，旧版已保存 Overlay=true 的设置也不会让新版勾选性能统计。
- 早前已核对本机 Tailscale 1.104.4 的 CLI 参数，并在获准访问本机服务后查询到一个可接收文件的设备；未向其发送文件。

界面检查截图：tests/output/window.png、installer-window.png、file-transfer-window.png、session-files-window.png。原生下拉框文字可能不被离屏截图捕获，选择值另有检查。

- 新增回归：在受控的独立进程 HWND 上真实注册并撤销 OLE 目标；使用真实 CF_HDROP 数据读取中文路径；100 次带左键状态的 DragOver 不制造传输；无 DragEnter 的 Drop、文本、仅移动操作、离开后投递、重复投递、会话停止后投递均拒绝；有效文件只提交一次；已有目标注册不会被失败尝试撤销。这些测试不移动用户鼠标，不操作用户游戏。

## 尚未验证

- 当前无法操作第二台电脑，没有进行真实跨网自动协商、文件落盘、双机 Ctrl+C/Ctrl+V、真实 OLE 拖放、目标位置、带宽或中断重试测试。
- Moonlight 实际窗口的原生 OLE 投递、流窗口识别、Explorer COM 活动文件夹、托盘常驻和真实远控结束的联动，仍需在实际桌面环境联调。
- 本次未执行管理员权限的防火墙修改，也未验证 Windows UAC 提示、不同账户权限、网络访问规则或跨网 TCP 48179 放行结果。
- 未改写用户系统剪贴板，未代替用户安装组件、登录账户或重新配对 Sunshine。
- 未验证 1080p 144 FPS、音频、时延、UAC 安全桌面、锁屏、休眠、多显示器/高 DPI、无显示器模式、ARM 或非 Windows 平台。

## 双机验收

1. 两端更新并运行新版；首次允许 Windows 网络权限。原有 Tailscale 同一账户、Send Files、Sunshine PIN 配对仍为先决条件。
2. 从主窗口开始远程，确认文件状态自动准备，不出现独立助手或口令步骤；仅出现 Moonlight 设备列表或错误时，确认不会同步文件剪贴板。
3. 在控制端复制一个中文名测试文件，等就绪通知后，在被控端目标文件夹粘贴并核对内容；反方向重复。
4. 把测试文件拖入远程画面，核对当前文件夹或桌面的保存位置；同名测试确认原文件未覆盖。
5. 关闭“文件状态”后重复一次；退出远程画面后确认不再处理新剪贴板，重连自动恢复。关闭主窗口确认托盘待命，右键退出确认后台结束。
6. 使用不同账户、旧版被控端或拒绝网络权限测试错误提示；文件协商失败时不应声称文件功能已启用。
7. 确认新连接左上角无黄色参数；需要诊断时再主动开启统计。

仅在实际设备完成以上步骤后，才可声称双机体验与性能目标已经验收。
1.3.1 补充验收：保持远控开启，切换至本机游戏或其他应用长按、拖动左键，确认不出现遮罩；回到本机资源管理器拖真实文件到远程画面，验证文件传输仍正常。未运行用户实际游戏或进行 Explorer 到真实 Moonlight 的端到端 OLE 拖放实测。
